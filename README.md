# Cortex V6 decision-lineage pack

This dedicated project pack records the architecture decision trail for Cortex V6 and its boundary with FOSSIL. It is deliberately separate from `fossil-ai-systems`: V6 is the project whose decisions are being recorded, while FOSSIL remains the durable knowledge/evidence subsystem described by those decisions.

The public ChatGPT share page is represented only as a reconstructed checkpoint. The locked V6 plan, Issue #9, and PRs #20–#24 are captured separately as primary source snapshots. `docs/DECISION_LINEAGE.md` is the human-readable view; immutable artifacts, snapshots, conversations, lineage, and events are the durable record.

This directory is local staging output. It does not modify or publish to the official FOSSIL repositories.
